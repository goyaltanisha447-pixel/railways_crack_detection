 Pin Connections

## Arduino Uno ↔ L298N
- IN1 → D8
- IN2 → D9
- IN3 → D10
- IN4 → D11

## IR Sensor
- VCC → 5V
- GND → GND
- OUT → D2

## GPS Module
- RX → D4
- TX → D5
- VCC → 5V
- GND → GND

## GSM Module
- RX → D6
- TX → D7
- GND → GND

## Ultrasonic Sensor
- TRIG → D12
- ECHO → D13
- VCC → 5V
- GND → GND
